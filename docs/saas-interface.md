# AI Job Hunter — SaaS interface MVP

Open `web/index.html` locally in a browser to preview the proposed user experience.

This is a **static UX prototype**. The two profile options represent sample configurations, not authenticated users. Cards are explicitly examples, and KPI values are intentionally unavailable (not invented).

## Principles
- Remote-first for every profession. Remote eligibility for Brazil needs verification.
- Manufacturing project managers and coordinators are equally eligible by title.
- Manufacturing careers must not silently become IT jobs.
- Onsite/hybrid: optional radius in kilometers from user-chosen city; Haversine distance is straight-line, not travel time.
- Commercial foundation will require authentication, authorization, private data storage and tenant isolation before any users' personal data can be uploaded.
- Do not serve user CVs, Gmail tokens or application data through GitHub Pages or this static prototype.
